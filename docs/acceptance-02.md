## 开发者浏览器自检：通过

1. 确认四个任务后可选择各任务历史字段；未选择字段时不会自动推荐。
2. 产值 LEFT 成本，项目编码与数据月份两条条件以 AND 展示；未填完整时有提示。
3. 同一编码展示“项目编码 / 工程编码”；同名“项目名称”按编码区分。
4. 交换左右任务后，保留侧说明、两侧字段同步交换；原校验状态失效。
5. 已选四任务只配置一组也能确认；两个互不连通的组能分别配置并通过校验。
6. 重复添加同一任务对有提示；可逐条删除条件、删除整组。空组不能通过确认。
7. 修改任务选择后暂停关系编辑；重新确认会移除相关组。
8. 补充新增劳务任务及关联组，再取消劳务任务：只移除劳务相关组，原两组的条件、类型和方向完整保留。
9. 单个任务无需关联，可确认 0 组配置。
10. 最终页面保留产值、成本、材料三个任务及两组配置，服务器校验通过。
