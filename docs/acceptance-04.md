## 真实 Ollama 联调：通过

真实调用记录保存在忽略跟踪的 .runtime/ollama-single.json、ollama-join.json、ollama-clarify.json。

- 单任务：按项目名称汇总项目总成本，生成 SUM 和 GROUP BY 及柱状图建议。
- 双任务：按月份对比项目总成本、材料金额，生成 LEFT JOIN，项目编码与月份条件均保留 BINARY 相等，返回两条度量和折线图建议。
- 无关联：模型首轮尝试无条件连接，服务器拒绝并反馈；模型返回需要补充关联的中文问题，未返回可执行结果。
- 首次冷启动约 75 秒，加载后请求约 3–6 秒；该性能仅代表本次本机测试。

## 浏览器自检：通过

- 生成表头后“智能分析”页签启用，底部主按钮切换为“生成分析 SQL”。
- 空输入有提示；真实模型返回业务说明、图表建议、格式化 SQL 和模型名。
- 修改提示词立即隐藏旧结果；生成中取消任务后，迟到的模型响应不会恢复旧结果。
- 未配关系的双任务分析显示“需要补充信息”，不显示 SQL。
- 字段映射、完整 SQL 可按需展开，保持单页左右工作区。
- 界面明确标注“尚未执行数据查询”，没有伪造数字或图表。
